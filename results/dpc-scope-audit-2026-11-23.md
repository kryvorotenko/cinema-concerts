## Знайдені розбіжності

1. О6.1 вимагав зупинки власника, а попередній дослід використовував `pause` (частина сценарію О6.3). Скрипт тепер за замовчуванням робить `stop/start`; окремий `pause` лишився доступним. Новий дослід пройшов.
2. Картка C01 задає тіло `POST /v1/scans` з `scan_id,ticket_id,gate,sector_id,event_time`; поточний DPC контракт додатково вимагає `ticket_code`. Поки Web надає читання тільки за кодом, треба узгодити спосіб отримання коду за `ticket_id` або змінити спільний контракт. Канонічне тіло з картки зараз не приймається — це **відкритий інтеграційний розрив**.
3. Документ ЛР1 помилково називав міграцію 002 після перенумерації у 010; загальний контракт помилково називав лише ЛР1/2 готовими. Обидва записи виправлено.
4. О6.3 не виконано повністю: pause/fencing перевірено, але окремого unsafe-досліду без fencing немає. О1.5, О2.2, О3.2 та інші необов'язкові пункти не заявляються.

ЛР4/5 належать іншому учаснику; ця звірка не оцінює їхні окремі гілки. Сквозне підтвердження з Web залишається окремим завданням після появи Web API й Web reserve.
