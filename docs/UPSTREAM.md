# Походження каркасів

Вихідні матеріали завантажено 18 листопада 2026 року.

| Каталог | Джерело | Commit |
|---|---|---|
| `web/` | https://github.com/a-kovt/web-interactions-course | `49fc428e6762a9878cbc5d76f5d85370704cad91` |
| `dpc/` | https://github.com/a-kovt/distributed-parallel-computing-course | `527d71875833c0b242d169d752141046002bd936` |

Обидва каркаси включено звичайними файлами в один репозиторій,
без вкладених Git-репозиторіїв або submodules. Ліцензія джерел — MIT,
автор — Andrii Kovtunenko; оригінальні файли LICENSE збережено.

У спільному проєкті створено єдиний кореневий `docker-compose.yml`, спільні
PostgreSQL, Kafka, міграції, константи, перевірки та документацію. Початкові
Compose-файли курсів прибрано. Частина матеріалів у `web/` і `dpc/` збережена
як довідка оригінальних комплектів: їхні автономні адреси й команди можуть не
відповідати спільному проєкту. Актуальні команди й порти — в кореневому README
та `docs/contracts/README.md`. Предметні приклади джерел описують бібліотеку,
не готову реалізацію C01.
