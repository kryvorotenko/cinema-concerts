# Постоянная память C01

Создана 2026-11-18 после анализа двух методичек и присланного командного плана.
Задача этой базы — не разбирать 188 страниц PDF при каждом продолжении работы.
В память включены общие правила, все 12 лабораторных, все нумерованные критерии,
обе карточки C01, границы интеграции, распределение команды и расхождения.
Остальные темы не являются требованиями нашего проекта.

Для обычной задачи достаточно PROJECT и одного раздела WEB/DPC. Для точной
проверки критерия используй requirements.json. Архив исходного текста нужен
только для деталей: он сохраняет ошибки извлечения PDF (переносы слов, `105`
вместо `10^5`, разрывы формул). Число строк для больших наборов — **100 000**.
Функция C01 и карточка Web дополнительно проверены на изображениях страниц.
Номера страниц в памяти — номера страниц PDF, совпадающие с печатными в источниках.

## Статус и происхождение правил

- **Требование курса:** источник — соответствующая методичка, раздел 1/2 или карточка C01.
- **Договорённость команды:** источник — присланный план; роли участников сохранены.
- **Вывод анализа:** явно отмеченное сопоставление источников; не новая договорённость.
- **Предложение/открытый вопрос:** не считать утверждённой архитектурой или заданием.

При несовпадении технического предположения плана с карточкой не меняем молча
ни требования курса, ни договорённость: фиксируем расхождение и запрашиваем
решение перед зависимой реализацией. Пользователь может явно выбрать адаптацию;
тогда записываем её как решение и объясняем, как сохраняются требования.
